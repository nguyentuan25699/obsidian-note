Imagine you're building a website for a new business, or you're running an existing web app on an aging on-premises server. Setting up a new server can be challenging. You need the appropriate hardware, likely a server-level operating system, and a web-hosting stack.
	Hãy tưởng tượng bạn đang xây dựng một trang web cho doanh nghiệp mới, hoặc bạn đang vận hành một ứng dụng web hiện có trên một máy chủ tại chỗ đã cũ. Việc thiết lập một máy chủ mới có thể rất khó khăn. Bạn cần phần cứng phù hợp, có thể là hệ điều hành cấp máy chủ, và một gói dịch vụ lưu trữ web.

Once it's running, you need to maintain the server. And what happens if your website traffic increases? You might need to invest in more hardware.
	Sau khi máy chủ hoạt động, bạn cần phải bảo trì nó. Và điều gì sẽ xảy ra nếu lưu lượng truy cập trang web của bạn tăng lên? Bạn có thể cần đầu tư thêm phần cứng.

Hosting your web application using Azure App Service makes deploying and managing a web app easier when compared to managing a physical server. In this module, we implement and deploy a web app to App Service.
	Lưu trữ ứng dụng web của bạn bằng Azure App Service giúp việc triển khai và quản lý ứng dụng web dễ dàng hơn so với việc quản lý một máy chủ vật lý. Trong module này, chúng ta sẽ triển khai và cài đặt một ứng dụng web lên App Service.
