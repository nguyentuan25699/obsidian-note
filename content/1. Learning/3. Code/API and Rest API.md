
## 1. What is API
- API: Application programing interface
- Set of programming code that enables data transmission between one software product and another.
- It also contains the terms of this data exchange.

## 2. What is REST, RESTful API
- REST: REpresentational State Transfer is a software architectural style that defines a set of constraints to be used for creating Web services
- RESTful API are APIs that follow REST architectures and rules.

## 5. Advantages & disadvantages of REST, RESTful API
### Advantages:
- Gain desirable non-functional requirements such as: performance, scalability, simplicity, modifiability, visibility, portability, and reliability.

### Disadvantages:
- Security and authentication may not be guaranteed by SOAP(stateless).
