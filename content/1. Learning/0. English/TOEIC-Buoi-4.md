# Buổi 4 — So sánh hơn (Comparative) và So sánh nhất (Superlative)

## 1. Ngữ pháp

### 1.1 Tính từ ngắn (1 âm tiết, hoặc 2 âm tiết tận cùng bằng -y)

So sánh hơn: adj + er (+ than)

- fast → faster than
- easy → easier than (y đổi thành i trước khi thêm er)

So sánh nhất: the + adj + est

- the fastest
- the easiest

### 1.2 Tính từ dài (2 âm tiết trở lên, không tận cùng bằng -y)

So sánh hơn: more + adj (+ than)

- efficient → more efficient than
- reliable → more reliable than
- popular → more popular than

So sánh nhất: the most + adj

- the most efficient
- the most reliable

### 1.3 Tính từ bất quy tắc

- good → better → the best
- bad → worse → the worst

### 1.4 Ví dụ trong ngữ cảnh IT

- This server is faster than the old one.
- Our new API is more reliable than the previous version.
- This is the best solution we have found so far.
- That bug was the worst issue we had last quarter.

## 2. Lỗi thường gặp

Lỗi 1: so sánh kép (double comparative) — kết hợp "more" với tính từ đã có đuôi "-er". Đây là lỗi cần tránh tuyệt đối.

Sai: more easier, more faster, more better Đúng: easier, faster, better (chỉ chọn một cách so sánh duy nhất)

Lỗi 2: dùng "has/have" với tính từ thay vì "is/are". Quy tắc: is/are đi với tính từ; has/have đi với danh từ hoặc động từ ở dạng quá khứ phân từ (V3).

Sai: This code has more efficient than the old one. Đúng: This code is more efficient than the old one.

Lỗi 3: quên "the" trước so sánh nhất.

Sai: This is best approach I've seen. Đúng: This is the best approach I've seen.

## 3. Giao tiếp IT — Email công việc

Mở đầu email:

- I hope this email finds you well.
- I'm writing to update you on...

Báo cáo tiến độ:

- I wanted to give you a quick update on the project status.

Xin thông tin/làm rõ:

- Could you please clarify the requirements for...?

Xin thêm thời gian:

- Due to some unexpected issues, we may need a few more days to complete this.

Kết thúc email:

- Please let me know if you have any questions.
- Looking forward to your feedback.

Ví dụ email đề xuất giải pháp (so sánh 2 phương án): "Dear John, I'm writing to update you on the checkout function we completed last week. As you know, I found a bug and fixed it. But now, when I rechecked it on the staging environment, I faced some performance issues. I've implemented and checked two solutions to improve performance. The first one involves using a new checkout function; I think this function is better than the old one. But I think the second one, which uses a new library, is the best solution we can use. It is more efficient, readable, and easier to maintain, and it increases app performance by up to 30%. Please take a look when you have time."

## 4. Từ vựng mới (kèm IPA)

|Từ|IPA|Nghĩa|Ví dụ|
|---|---|---|---|
|performance|/pərˈfɔːrməns/|hiệu năng|The new version improved app performance.|
|optimize|/ˈɑːptɪmaɪz/|tối ưu hóa|We need to optimize this query.|
|efficient|/ɪˈfɪʃnt/|hiệu quả|This solution is more efficient than the old one.|
|compare|/kəmˈper/|so sánh|Let's compare the two approaches.|
|reliable|/rɪˈlaɪəbl/|đáng tin cậy|We need a more reliable server.|
|improve|/ɪmˈpruːv/|cải thiện|This update will improve loading speed.|

## 5. Bài tập đã làm trong buổi (để ôn lại)

1. This solution is more efficient than the previous one.
2. React is more popular than jQuery nowadays.
3. This is the best approach I've seen so far.
4. The new server is faster than the old one.
5. Of all the bugs this month, this one is the worst.
