# Buổi 7 — Liên từ (and/but/because/so) và Word Form

## 1. Ngữ pháp

### 1.1 Liên từ cơ bản

|Liên từ|Ý nghĩa|Ví dụ|
|---|---|---|
|and|nối 2 ý cùng chiều, bổ sung|I fixed the bug and deployed it.|
|but|nối 2 ý đối lập|I fixed the bug, but I haven't deployed it yet.|
|because|chỉ nguyên nhân|The release was delayed because of a critical bug.|
|so|chỉ kết quả|There was a critical bug, so the release was delayed.|

Lưu ý cấu trúc:

- because + mệnh đề (S + V) hoặc because of + cụm danh từ (không có động từ).
    - The release was delayed because the API failed. (mệnh đề đầy đủ)
    - The release was delayed because of the API failure. (cụm danh từ, không phải mệnh đề)
- so luôn đứng giữa 2 mệnh đề, có dấu phẩy trước nó khi nối 2 câu độc lập.
    - The server crashed, so we had to restart it.

### 1.2 Word Form (Danh từ / Động từ / Tính từ / Trạng từ cùng gốc)

Trong TOEIC Part 5/6, rất hay gặp dạng bài cho 1 từ gốc, yêu cầu chọn đúng dạng từ loại (noun/verb/adjective/adverb) để điền vào câu.

Ví dụ một số từ IT hay gặp, biến đổi theo 4 dạng:

|Danh từ (N)|Động từ (V)|Tính từ (Adj)|Trạng từ (Adv)|
|---|---|---|---|
|efficiency|—|efficient|efficiently|
|improvement|improve|improved|—|
|reliability|rely (on)|reliable|reliably|
|responsibility|—|responsible|responsibly|
|requirement|require|required|—|

Cách nhận biết vị trí cần điền từ loại nào trong câu:

- Sau a/an/the hoặc tính từ sở hữu (my, our, the team's...) → cần danh từ. Ví dụ: the team's efficiency.
- Đứng làm chủ ngữ/tân ngữ chính của câu → danh từ.
- Bổ nghĩa cho danh từ (đứng trước danh từ) → tính từ. Ví dụ: an efficient solution.
- Sau to be (is/are/was...) → thường là tính từ. Ví dụ: This solution is efficient.
- Bổ nghĩa cho động từ (thường đứng cuối câu hoặc trước động từ chính) → trạng từ. Ví dụ: He works efficiently.
- Là hành động chính trong câu, đi sau chủ ngữ → động từ. Ví dụ: We need to improve this process.

## 2. Lỗi thường gặp

Lỗi 1: dùng "because" với cụm danh từ (thiếu động từ) thay vì "because of".

Sai: The release was delayed because the API failure. Đúng: The release was delayed because of the API failure. (hoặc: because the API failed — thêm động từ)

Lỗi 2: chọn sai từ loại khi điền vào câu — đặc biệt là nhầm vị trí cần danh từ (sau sở hữu cách 's) thành tính từ. Đây là lỗi rất điển hình trong Part 5.

Sai: The new process improved the team's efficient. Đúng: The new process improved the team's efficiency. (sau "the team's" luôn cần danh từ)

Sai: This is a efficiency solution. Đúng: This is an efficient solution. (đứng trước danh từ "solution" → cần tính từ)

Sai: He works very efficiency. Đúng: He works very efficiently. (bổ nghĩa cho động từ "works" → cần trạng từ)

Lỗi 3: thiếu từ nối trong mệnh đề quan hệ đầy đủ, hoặc quên rút gọn đúng cách với V3 khi mệnh đề mang nghĩa bị động.

Sai: I have a blocker with the task was assigned to me yesterday. Đúng (đầy đủ): I have a blocker with the task that was assigned to me yesterday. Đúng (rút gọn): I have a blocker with the task assigned to me yesterday.

## 3. Giao tiếp IT — Standup / Báo cáo tiến độ hàng ngày

Standup là buổi họp đứng ngắn hàng ngày (thường 10-15 phút), mỗi người báo cáo 3 ý chính: hôm qua làm gì, hôm nay làm gì, có vướng mắc gì không.

- Hôm qua đã làm: Yesterday, I finished the login feature and fixed two bugs.
- Hôm nay sẽ làm: Today, I'm going to work on the payment module.
- Có vướng mắc (blocker): I'm blocked by an issue with the API — I need help from the backend team.
- Không có vướng mắc: I don't have any blockers today.

Ví dụ đoạn báo cáo standup hoàn chỉnh (dùng liên từ but và because): "Yesterday, I was assigned one feature and two bugs. I finished the new feature, but I didn't deploy it because I had a blocker with the bug. I'm blocked by an issue with the API — I think this bug belongs to the backend team, and I need help from them to check it. Today, I'll finish those bugs and deploy them to staging. That's all about my report."

## 4. Từ vựng mới (kèm IPA)

|Từ|IPA|Nghĩa|Ví dụ|
|---|---|---|---|
|standup|/ˈstændʌp/|buổi họp đứng ngắn hàng ngày|We have a standup every morning at 9 AM.|
|blocker|/ˈblɑːkər/|vướng mắc gây cản trở công việc|I'm blocked by an API issue — I have a blocker.|
|assign|/əˈsaɪn/|giao (nhiệm vụ)|This task was assigned to me yesterday.|
|available|/əˈveɪləbl/|rảnh, có thể sử dụng được|Are you available for a quick call?|
|reproduce|/ˌriːprəˈduːs/|tái hiện (lỗi)|I can't reproduce this bug on my machine.|
|workaround|/ˈwɜːrkəraʊnd/|giải pháp tạm thời|We found a workaround for now, but we need a real fix later.|

## 5. Bài tập đã làm trong buổi (để ôn lại)

Phần A — liên từ:

1. I tested the feature, but it still has a bug.
2. The deployment failed because the server ran out of memory.
3. We fixed the bug and deployed it the same day.

Phần B — word form: 4. The new process improved the team's efficiency significantly. (danh từ, sau "the team's") 5. Please make sure the system is reliable before launch. (tính từ, sau "is") 6. She completed the task responsibly. (trạng từ, bổ nghĩa cho động từ "completed")
